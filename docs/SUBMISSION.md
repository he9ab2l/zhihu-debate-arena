## 作品简介

面对职业、学习和生活选择时，我们往往不缺观点，缺的是观点之间的结构。知乎思辩台在登录后调用知乎开放平台站内搜索，将真实摘要、原文链接和来源字段整理成证据卡，再通过“立论—攻防—终局”三回合交锋，帮助用户看见支持与质疑背后的隐含条件。它不替用户投票，也不生成演示来源；最终留下的是能结合个人处境执行的检查清单。

## 产品亮点

## 推荐演示路径

打开 [https://link.heabl.xyz/zhihu](https://link.heabl.xyz/zhihu)。先展示左侧“我的辩题”历史，再打开“今日热榜”，说明热榜只用于发现议题。随后输入议题并点击“开始拆解”；未登录时展示登录提示，登录后展示真实检索结果。

进入结果页后，依次展示支持/质疑视角、证据库、三回合的“立论—攻防—终局”，以及独立滚动的长摘要。最后打开 AI 总结，分别展示“单篇证据”“整场辩题”和“三回合综合”。强调 AI 输出只基于当前真实摘要，并不替用户投票。

## 评审边界

项目只展示真实知乎检索结果。没有有效来源时不会生成演示辩题。Access Secret、AI API Key 和 AI API URL 均为服务端 Secret，不放入仓库、视频或公开文本。

当前登录流程使用 Manus OAuth。知乎 OAuth 回调接口属于下一阶段联调项，需要知乎开放平台 OAuth 应用凭证后才能完成授权、回调和账号绑定，不在没有凭证时伪造接入状态。

## 视频口播稿

这是知乎思辩台。当你面对一个没有标准答案的选择，它不会替你投票，而是先把分歧摆在桌面上。

输入议题后，登录用户可以发起知乎站内检索。系统把真实检索摘要、原文链接和来源字段整理成证据卡。未登录用户只能浏览已经保存的真实辩题，不能消耗新的检索额度。

接下来，材料被组织成支持视角和质疑视角。这里的标签是产品的阅读视角，不冒充原作者立场。三回合交锋从立论开始，经过攻防，最后把观点转换成今天可以执行的判断条件。

用户还可以打开证据库，在右侧面板中逐篇核验原文；长内容只在面板内部滚动，不会把整个页面拉得很长。AI 总结支持单篇证据、整场辩题和三回合综合，但它只使用当前真实摘要，不补造作者、数据或来源。

最后留下的不是替用户做好的决定，而是一张检查清单：损失是否可逆，安全垫是否足够，能不能先做一个低成本试验。知乎思辩台，把观点交锋变成自己的判断条件。
